# Fonts (optional)

BeriPost uses a clean built-in font by default, so you do not need to add
anything here.

If you want a specific brand font on your images, drop a `.ttf` file in this
folder and set its filename in `config.yaml` is not required - instead, name it
`headline.ttf` (bold) and `body.ttf` and BeriPost will pick them up
automatically. If they are missing, it falls back to a default font.
