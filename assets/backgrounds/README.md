# Background images

Drop your pre-approved background images in THIS folder (`.jpg` or `.png`).

BeriPost rotates through them when composing post images, adds a subtle dark
overlay for text readability, then places your logo and the post headline on
top. This keeps image cost at zero.

Tips:
- Use warm, calm, on-brand photos (families, caregivers, hands, home settings).
- Landscape or square images work best. They are auto-cropped to 1080x1080.
- 3 to 8 images is plenty. The more you add, the more variety in your feed.
- If this folder is empty, BeriPost falls back to a solid brand-color
  background so it still works.
